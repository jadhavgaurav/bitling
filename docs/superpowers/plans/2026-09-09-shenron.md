# Shenron Desktop Pet Implementation Plan

**Goal:** Replace Ember with a recognizable, large Shenron that flies across the desktop.

**Architecture:** Preserve the saved `dragon` species ID. Use detailed transparent sprite art, a deformable mesh, and a shared pose for rendering, speech and attack origin. Give this species a screen-sized click-through native stage. Canvas motion owns cruising and dragging inside that stage; existing native motion remains responsible for other pets.

**Reference:** User supplied Shenron illustration; Dragon Ball official S.H.Figuarts Shenron reference https://en.dragon-ball-official.com/special/sdcc2022/items/shenron.php . Essential anatomy: long green scaled coils, gold plated belly, red eyes, brown branched horns, four clawed limbs, mane, long whiskers, no wings.

**Tradeoffs:** Enlarging the ordinary pet window retains its movement constraints. A procedural drawing supplies articulation but would lose the reference's detailed likeness. Selected approach: transparent illustrated sprite animated with a mesh on a full display stage. This preserves recognizable art with smooth deformation; it is a 2D animated pet, not a 3D anatomical simulation.
